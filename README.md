# acb-course-prep

DEX401 supplementary material: the "big picture" of Mule applications and application networks in the Agentic Enterprise — System API (DEX401-1) and Process API (DEX401-2) — told through the course's Mule United Airport scenario.

- Site source: [`docs/index.html`](docs/index.html) (single page, no build step)
- Languages: 日本語 / 한국어 / English (switch in the top bar, or `?lang=ja|ko|en`)

## Publish on GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, Folder: `/docs`.

Unofficial instructor material. Course PDFs and student files are excluded via `.gitignore` and must not be committed.
